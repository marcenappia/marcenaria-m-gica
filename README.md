# Marcenaria Mágica

Crie um novo projeto independente chamado Oficina IA — Projetista de Marcenaria. Não modifique nenhum projeto existente. Quero um app full-stack em português brasileiro para upload de foto real de ambiente, descrição natural da marcenaria, campos separados de medidas de armários superiores/inferiores, análise estruturada, geração real de render por provedor server-side configurado, biblioteca de projetos, persistência e exportação PDF. Não faça landing page estática nem botões falsos. Nunca invente medidas exatas a partir de foto; identifique dimensões informadas/estimadas/pendentes. Upload com preview persistente, fluxo de análise, render com estados de loading/erro/retry, salvamento da foto original e do resultado verdadeiro. Segurança: API keys apenas no servidor, validação de upload. Design profissional, responsivo, arquitetura de interiores e marcenaria. Referências técnicas para avaliar: Hugging Face Diffusers ControlNet https://huggingface.co/docs/diffusers/using-diffusers/controlnet ; https://github.com/huggingface/diffusers ; stable-diffusion.cpp image editing https://github.com/leejet/stable-diffusion.cpp/blob/master/docs/edit.md . Avalie licenças e custos; não alegue que um modelo está hospedado sem confirmar. Se faltarem credenciais de IA, mostre diagnóstico explícito e não simule sucesso. Implemente e teste o máximo real possível.
